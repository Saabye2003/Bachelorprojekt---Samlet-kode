# Bachelorprojekt - kode
Nærmere beskrivelse findes i dokumenterne, hvor koden også er beskrevet "relativt" udførligt

Rækkefølgen i dokumenterne er beskrevet internt i de 6 dokumenter, men følger følgende struktur

Acerbi teststørrelser -> Tabel1+2 Acerbi -> Tabel3 Acerbi -> Sensitivitetsanalyse -> GARCH-model og kritisk værdi -> HS og VHS

Dokumenterne er opdelt for overskuelighedens skyld, og indeholder primært ting, der omhandler den kode

Dokumenterne indeholder funktioner der går på "tværs" af dokumenter, så hvis fejlkode viser, er det nok fordi funktionen fra tidligere
mangler at blive loadet
